# Bllii 桌面安装 / 卸载界面设计

打开 `index.html` 即可离线预览。也可以在仓库根目录运行：

```powershell
node video-collection-app/installer/design/preview-server.mjs
```

浏览器访问 http://127.0.0.1:4178/video-collection-app/installer/design/index.html 。端口可通过 `BLLII_PREVIEW_PORT` 指定。

## 视觉

- 使用品牌包的原始 SVG 字标、播放图形及加载动画，不重绘标志。
- 蓝 `#4B9FFF`、紫 `#9A83FF`、粉 `#FF89C7` 用于品牌主视觉和进度；深墨 `#353B58` 用于正文。主按钮使用较深蓝紫色保证白字可读性。
- 桌面向导约 1040 × 605 px（包含标题栏），品牌区 / 操作区比例为 37 / 63；按钮高 44 px、圆角 9 px，窗口圆角 18 px。
- 左侧常驻品牌视觉，右侧每页只保留一个主要动作。卸载沿用同一视觉语言，避免挽留弹窗和强制反馈。
- 小屏预览隐藏品牌侧栏，保留全部操作。尊重系统减少动态效果设置。

## 页面与交互

| 流程 | 页面 | 交互 |
| --- | --- | --- |
| 安装 | 准备安装 | 自定义安装路径、桌面快捷方式、安装后启动 |
| 安装 | 安装中 | 真实语义的进度条、三阶段状态、演示进度自动完成 |
| 安装 | 安装完成 | 按已选偏好显示启动或完成、快捷方式提示 |
| 卸载 | 卸载确认 | 默认保留本地数据，另可选择清除 |
| 卸载 | 卸载中 | 移除文件及数据处理状态 |
| 卸载 | 卸载完成 | 明确反馈数据保留或清除结果 |
| 两者 | 异常状态 | 可恢复的失败说明、重试与返回 |

顶部预览控件可直接查看任意状态。直接选择“安装中 / 卸载中”会停在 56% 方便评审；从主按钮进入时自动播放完整演示。URL 支持 `?flow=uninstall&screen=success` 等参数。标题栏的关闭、最小化均只影响预览。

## 接入边界

这是界面设计与交互原型，不执行安装、启动程序或删除文件。版本 1.0.1 来自当前 `bllii.iss`；生产界面应由打包版本注入。路径是可编辑示例，生产默认目录应由 Inno Setup 展开。

现有 `../bllii.iss` 仍使用 Inno Setup 原生向导，未因本设计修改。HTML/CSS 不能直接充当 Inno Setup 皮肤：落地时需使用自定义向导控件或安装器壳层，复用本目录的布局、文案和状态规则，并绑定实际文件操作进度。

当前原生卸载器没有“清除本地数据”的实现。接入该选项时，必须核实 Flutter SharedPreferences 的实际存储位置，仅处理 Bllii 所属目录；清除前再次确认，取消后不清理。原型中的保留 / 清除结果仅模拟用户选择。

生产中还需将磁盘空间、写权限、应用占用检查接入真实检测；卸载过程中应拦截关闭，出现错误时保留可重试状态。原型没有伪造包体积、剩余秒数或用户协议。
