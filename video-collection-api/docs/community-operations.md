# 账号权限、审核与积分运营

## 后台角色

| 角色 | 查看范围 | 操作权限 |
| --- | --- | --- |
| 超级管理员 `super_admin` | 全部后台 | 全部管理；分配后台角色；数据库、插件和系统配置维护 |
| 管理员 `admin` | 全部后台 | 内容发布与审核、普通会员管理、采集管理、求片处理、积分规则、商店、通知；不能授权或修改后台员工、运行管理 SQL、恢复数据库、安装插件或修改系统配置 |
| 观察员 `observer` | 全部后台 | 业务只读；页面保留操作入口，但服务端拒绝写入；可阅读自己的消息及使用自己的积分装扮 |
| 运营人员 `operator` | 仪表盘、视频、资讯、社区、本人审核提交和消息 | 提交视频、资讯、帖子及评论；不能直接发布、删除、采集、审核、广播通知或管理账号 |
| 普通会员 `user` | 前台 | 评论、社区发帖、积分、求片、装扮、个人消息；无后台权限 |

超管通过“用户账号管理”新建或修改员工角色。只有超管能变更任何员工账号，管理员只能管理普通会员。不能删除、禁用或降级自己的账号；数据库事务保证至少保留一位启用的超管。所有请求重新读取账号状态，禁用或改角色会立即生效。

观察员的只读限制由 API 强制执行，隐藏按钮不是授权依据。个人签到、装扮和消息已读属于个人账户功能。后台写入请求会记录到“运行审计日志”的操作记录，包含操作人、接口、时间和 HTTP 结果；密码和请求正文不进入该记录。

## 运营发布与审核

在“视频仓库”新增资料或编辑现有视频，或者在资讯、社区页面提交内容。运营在前台发帖、评论也会进入同一队列。提交成功返回 `pending=true` 和 `review_id`，不能把此响应当作已公开发布。

待审核内容保存在 `content_reviews`，不会写进公开视频/资讯/帖子/评论库。编辑已公开内容时，审核期间继续展示原版本。管理员、超管在“内容审核中心”查看完整资料、播放线路及提交人，通过或填写原因拒绝。批准和实际保存内容在同一事务中完成，重复审核不会重复发布。审核人不能审核自己提交的内容。

审核前原内容若被管理员或采集更新，批准会返回 409，防止旧提案覆盖新资料。先拒绝此提案，再让运营基于最新资料重新提交。被拒绝的提交可在队列中修改 JSON 后再次提交；视频、资讯、帖子也可回到对应编辑页提交。

运营提交后会通知所有正常管理员与超管；结果会通知提交人。管理员直接创建内容可即时发布，普通会员社区互动继续沿用原有发布流程。采集任务由管理员及超管管理，使用可信系统身份保存，不属于运营手工提交。

## 日活与积分

规则保存在数据库 `growth_settings`，后台“日活 / 积分 / 装扮”可调整，不需要改代码。所有日界线均按北京时间（UTC+8）。

| 默认规则 | 值 |
| --- | --- |
| 登录后每天首次使用认证接口 | 5 积分，一天一次，同时计入 DAU |
| 每日签到基础奖励 | 10 积分 |
| 连续签到每天增量 | 2 积分 |
| 单日签到奖励封顶 | 30 积分 |
| 每次积分求片 | 20 积分 |

DAU 为每天使用过认证接口的去重账号数，包含后台员工，不统计匿名访问量。最近30天展示日活、签到、发放/退款和消费。修改规则只影响之后发生的奖励及消费，历史求片按原支付金额退款。

积分操作锁定钱包行并使用唯一事件流水，重复签到、重复兑换与并发操作不会多发奖励、多扣积分或产生负余额。余额、库存、求片和对应流水在同一事务保存。前台展示最近100笔流水，完整流水持久化在 `point_ledger`。

## 积分求片

Web 用户菜单 →“同好成长站”；App“我的”登录后 →“同好成长站 / 消息”。填写片名与线索并确认扣分。每人最多5个未完成求片，同名未完成求片不能重复提交。

管理员在“积分求片”更新为寻找中、已完成或未采纳，并填写处理说明。完成说明可填写观看链接。未采纳会自动退还原扣除积分，重复处理不会重复退款；完成和未采纳均为终态。每次状态变更通知用户。此前匿名反馈接口仍作为普通留言保留，积分求片走新的认证接口。

心愿默认仅本人和管理员可见。本人可主动邀请同好助力，确认公开昵称、作品名及线索后，未完成心愿才进入公共心愿墙；可以随时收回公开，已有助力保留。完成或未采纳后自动离开心愿墙。每个账号对同一心愿只能助力一次，不能助力自己的心愿，助力免费。运营和观察员不能公开或助力心愿。墙按助力数、创建顺序排序，后台求片列表展示助力数，供管理员安排找片优先级参考，不自动承诺完成时间。

## 同好成长日常

Web 的同好通行证展示积分、成长等级和装扮，七日签到路线按实际连续天数与当前积分规则展示。任务由服务端验证已保存的行为，领取奖励也写入唯一积分流水，重复或并发领取只奖励一次。

| 初始任务 | 验证条件 | 周期 | 奖励 |
| --- | --- | --- | --- |
| 把故事看下去 | 当天同步一个仍存在作品的云端观影记录 | 每日 | 10 |
| 收藏第一份心动 | 收藏一个仍存在的作品 | 一次 | 15 |
| 留下你的声音 | 已发布且未删除的留言 | 一次 | 20 |
| 七日相伴 | 历史连续签到达到7天 | 一次 | 50 |
| 为同好的期待亮灯 | 助力另一位同好的公开心愿 | 一次 | 10 |

观影任务验证的是云端记录同步，不测量实际观看时长。运营待审核留言不计入已发布留言。每日任务按北京时间重置；历史行为只满足一次性任务，不能重复用于第二天的每日任务。

后台“成长任务”可新增、编辑名称、说明、目标、奖励和启用状态。目标范围1–100，奖励0–500；行为类型支持 history/favorite/comment/checkin/support，周期支持 day/once，创建后类型与周期不可修改，以避免既有奖励流水被重新解释。签到类型按历史最大连续天数判断。观察员可查看，管理员与超管可修改。

成长值为历史正向积分收入的累计值，不包含退款。兑换与求片消费不会掉级，退款也不会刷成长值。初始等级为：初遇故事（0）、追番同好（100）、故事收藏家（300）、热爱领航员（800）、星光守护者（2000），保存在 `growth_levels`。当前后台不提供等级编辑。

## 装扮及消息

商店支持普通头像、动态头像、头像框、铭牌、彩色昵称。兑换后永久拥有，同一商品不重复收费；佩戴须已拥有，各类别同一时间一件，普通与动态头像共享头像位置。可卸下恢复原始外观。

Web 衣橱支持按类别筛选与免费试戴，试戴只在本页通行证预览，不扣积分、不保存佩戴；可恢复当前装扮。兑换前展示商品及积分花费确认，兑换后可正式佩戴。

后台可新增商品、改名称/图片/颜色/价格或下架。已创建商品类型不能改变，下架不取消已兑换权益。价格可设为0，其他价格上限100000。头像使用 HTTPS 图片（GIF 可作动态头像），或内置 `/api/cosmetics/orbit.svg`、`/api/cosmetics/pulse.svg`。头像框与昵称只接受六位十六进制颜色，铭牌最多12字，不接受任意 HTML/CSS。App 对内置星球头像提供原生动画；外部动图由图片组件播放。

Web 名片、导航头像、社区列表/详情作者、资讯作者、评论与楼中楼回复、发帖与评论输入区显示已佩戴装扮；头像框、铭牌、昵称颜色使用统一作者样式。展示按当前佩戴状态读取，更换或卸下后，旧内容在下次加载时同步更新，不需要重新发布。兑换但未佩戴的商品不会自动展示。App 个人档案和成长站显示装扮；App 当前没有社区评论页面。后端内容/评论输出 `author_avatar/author_frame/author_badge/author_color`，其他客户端可据此接入。

后台“消息通知”支持个人收件箱、已读、未读数和管理员定向/广播发送。顶部未读数每30秒刷新，离开页面释放定时器。Web 和 App 均有个人收件箱。

## 统一弹窗

Web 的评论删除、积分兑换、求片与公开心愿确认和故事口袋共用 `BrandDialog` 组件及全局弹窗服务。组件随页面预渲染，运行时更新文字及开关状态，不临时拼接或向页面插入弹窗节点，也不调用浏览器 alert/confirm/prompt。统一提供品牌标题、按钮、遮罩、手机布局、Esc/关闭按钮/遮罩关闭、滚动锁定和关闭后的焦点恢复；确认弹窗按队列处理，取消不会执行业务操作。后台沿用 Element Plus 组件，并统一对话框与确认框的圆角、颜色和明暗主题。

## 接口

均沿用 `{code:1,data:...}` 与 Cookie / Bearer 认证，错误返回适当 HTTP 状态。所有列表分页为 `page/page_size`，每页上限100。

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/me` | GET | 当前角色、装扮、余额及后台访问标记 |
| `/api/user/points` | GET | 钱包、签到状态、规则、最近100笔流水 |
| `/api/user/points/checkin` | POST | 签到；`data.earned=0` 表示今天已领过 |
| `/api/user/journey` | GET | 成长值、当前/下一等级、等级路线及任务进度 |
| `/api/user/missions/claim` | POST | `{key:任务键}`；已领取返回 `earned=0` |
| `/api/admin/missions` | GET / POST | 任务配置；key/name/description/kind/period/target/reward/active |
| `/api/movie-request-wall` | GET | 公开未完成心愿分页；匿名可读，登录返回本人助力状态 |
| `/api/user/movie-requests/share` | POST | `{id,shared}`；本人公开或收回未完成心愿 |
| `/api/user/movie-requests/support` | POST | `{id}`；免费助力其他同好心愿，重复幂等 |
| `/api/user/shop` | GET | 商店与本人库存、佩戴标记 |
| `/api/user/shop/redeem` | POST | `{id:商品ID}` 兑换 |
| `/api/user/shop/equip` | POST | `{id:商品ID}` 佩戴；`{id:0,slot:"avatar"}` 卸下，其他位置 frame/badge/nickname_color |
| `/api/user/movie-requests` | GET / POST | 自己的求片；提交 `{title,details}` |
| `/api/admin/reviews` | GET / POST | 队列可按 status 筛选；审核 `{id,approve,note}` |
| `/api/admin/movie-requests` | GET / POST | 求片处理 `{id,status,reply}` |
| `/api/admin/growth` | GET | 最近30天运营统计 |
| `/api/admin/growth/rules` | GET / POST | 读取/修改 active/checkin/streak_step/streak_cap/request_cost |
| `/api/admin/shop` | GET / POST | 商店管理，字段 id/name/kind/value/price/active |
| `/api/admin/audit` | GET | 后台操作记录 |

SQLite 与 PostgreSQL 共用上述事务实现。升级及备份操作见 [部署说明](../../deploy/README.md)。
